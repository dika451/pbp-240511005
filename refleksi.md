Platform yang paling menarik untuk saya pelajari adalah platform mobile. Menurut saya, aplikasi mobile dekat dengan kegiatan sehari-hari karena dapat digunakan kapan saja melalui ponsel. Selain itu, aplikasi mobile bisa memanfaatkan fitur perangkat seperti GPS, kamera, notifikasi, dan sensor. Saya ingin memahami bagaimana sebuah aplikasi dirancang agar mudah digunakan, tidak terlalu berat, dan tetap berjalan dengan baik pada perangkat yang memiliki spesifikasi berbeda.

Tantangan terbesar pada tahap setup environment adalah memastikan semua tools terpasang dengan benar dan dapat dikenali melalui terminal. Git, Node.js beserta NPM, Visual Studio Code, dan Java JDK memiliki fungsi yang berbeda, sehingga saya perlu memahami kegunaan masing-masing. Android Studio juga dapat membutuhkan ruang penyimpanan yang cukup besar, sehingga proses instalasinya perlu direncanakan sesuai kapasitas laptop dan koneksi internet.

Untuk mengatasi tantangan tersebut, saya akan menginstal tools satu per satu dari situs resminya, mengikuti petunjuk instalasi, lalu membuka terminal baru untuk memeriksa versi setiap tools. Jika perintah tidak dikenali, saya akan memeriksa kembali proses instalasi dan konfigurasi PATH. Saya juga akan mencatat kendala yang muncul dan mencari solusi melalui dokumentasi resmi atau bertanya kepada dosen dan teman. Setelah semua tools terverifikasi, saya akan membuat repository GitHub, melakukan clone ke komputer, lalu menyimpan dan mengunggah file tugas secara bertahap agar prosesnya lebih mudah diperiksa.
