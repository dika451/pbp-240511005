## 1. Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript/TypeScript; sisi server dapat memakai JavaScript, Python, PHP, Java, dan bahasa lain. | Bergantung pada teknologi, misalnya Java, C#, C++, Python, atau JavaScript dengan framework desktop. | Android umumnya memakai Kotlin/Java; iOS umumnya memakai Swift. Framework lintas platform juga tersedia. |
| Arsitektur | Umumnya menggunakan model client-server. Browser menjadi client yang meminta halaman atau data dari server melalui jaringan. | Umumnya aplikasi berjalan secara lokal di sistem operasi, tetapi dapat terhubung ke server atau layanan cloud. | Aplikasi berjalan pada perangkat mobile dan dapat menggunakan layanan perangkat seperti kamera, GPS, sensor, serta jaringan. Data dapat disimpan lokal atau di server. |
| Cara distribusi | Diakses melalui URL menggunakan browser. Pembaruan aplikasi biasanya dilakukan di server sehingga pengguna tidak perlu memasang versi baru secara manual. | Umumnya dipasang melalui installer, paket aplikasi, atau toko aplikasi desktop. Pembaruan dilakukan melalui updater, toko aplikasi, atau pemasangan versi baru. | Umumnya didistribusikan melalui Google Play, Apple App Store, atau distribusi APK/IPA sesuai platform dan kebijakan yang berlaku. |
| Keunggulan | Mudah diakses lintas perangkat, tidak selalu perlu instalasi, dan pembaruan terpusat. | Dapat memanfaatkan sumber daya komputer dan fitur sistem operasi; cocok untuk pekerjaan yang membutuhkan kemampuan lokal atau antarmuka kompleks. | Praktis dibawa, mendukung fitur perangkat seperti GPS dan kamera, serta cocok untuk penggunaan saat bepergian. |
| Keterbatasan | Pengalaman dan kemampuan dapat bergantung pada browser, koneksi internet, dan batasan akses ke fitur perangkat. | Perlu memperhatikan kompatibilitas sistem operasi dan proses instalasi/pembaruan; penggunaan ruang penyimpanan lokal dapat lebih besar. | Memiliki keterbatasan ukuran layar, baterai, memori, serta fragmentasi perangkat dan versi sistem operasi. |
| Contoh aplikasi | Google Docs versi web, Gmail di browser, sistem informasi berbasis web. | Microsoft Word desktop, Visual Studio Code, aplikasi kasir desktop. | WhatsApp, Google Maps, aplikasi mobile banking. |

## 2. Ringkasan Analisis

Tidak ada satu platform yang selalu paling baik untuk semua kebutuhan. Platform web sesuai untuk layanan yang perlu mudah diakses dari berbagai perangkat dan diperbarui secara terpusat. Platform desktop cocok untuk aplikasi yang memerlukan integrasi lebih kuat dengan sistem operasi atau pekerjaan lokal yang intensif. Platform mobile tepat untuk layanan yang digunakan sambil bergerak dan membutuhkan fitur perangkat seperti lokasi, kamera, atau notifikasi. Pemilihan platform sebaiknya mempertimbangkan kebutuhan pengguna, biaya pengembangan dan pemeliharaan, keamanan, ketersediaan jaringan, serta perangkat yang digunakan.
